숨밈 테스트 서버 런처

[처음 한 번]
1. 이 폴더를 바탕화면처럼 쓰기 편한 곳에 둬요. (C:\Program Files 안은 피하세요)
2. SumimLauncher.exe 를 두 번 클릭해요.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러요.
3. 왼쪽 아래 [Microsoft 로그인]을 눌러요.
   - Prism 창이 열리면 안내에 따라 정품 마인크래프트(Java 에디션) 계정으로 로그인해요.
   - 로그인을 마치고 Prism 창을 닫으면 런처에 내 이름이 보여요.

[게임하기]
- [게임 시작]만 누르면 모드가 자동으로 맞춰지고 서버로 바로 들어가요.
- 처음 시작할 때는 자바와 게임 파일을 받느라 몇 분 걸릴 수 있어요.

[자주 묻는 것]
- 쉐이더: 게임 안 설정 → 비디오 설정 → 쉐이더 팩
- 렉이 심하면: 런처 [설정] → 게임에 쓸 메모리를 올려요.
- 스크린샷: 게임에서 F2를 누르면 런처 [스크린샷]에 모여요.

prism 폴더는 지우거나 옮기지 마세요. 로그인과 게임 실행에 필요해요.
